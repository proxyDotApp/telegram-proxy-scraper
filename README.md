# Telegram Proxy Scraper & Meta Manager API 🚀

یک سرویس قدرتمند و بدون سرور (Serverless) بر پایه **Cloudflare Workers** برای استخراج خودکار پروکسی‌های MTProto از کانال‌های تلگرامی (بدون نیاز به لاگین). 
این پروژه به شما یک API با فرمت JSON می‌دهد و به کمک یک **ربات تلگرام** و پایگاه داده **Cloudflare KV**، به شما اجازه می‌دهد متادیتاهای API (مثل عنوان، لینک، بنر و وضعیت نمایش تبلیغات) را در لحظه و به صورت داینامیک مدیریت کنید.

---

## ✨ ویژگی‌های کلیدی
- 🕷️ **استخراج ابری و بدون اکانت:** استخراج پروکسی‌ها از طریق Telegram Web Preview بدون نیاز به ساخت اکانت تلگرام یا لاگین.
- 🤖 **مدیریت زنده با ربات تلگرام:** تغییر تمامی تنظیمات ظاهری API (Title, Description, Link, Image, Ads) مستقیماً از داخل تلگرام.
- ⚡ **سرعت فوق‌العاده (Edge Compute):** اجرا روی شبکه جهانی Cloudflare با بهره‌گیری از سیستم Caching برای پاسخ‌دهی در میلی‌ثانیه.
- 🗂️ **یکپارچه با Cloudflare KV:** ذخیره‌سازی دائمی و سریع تنظیمات متادیتا.
- 🔄 **سیستم Fallback هوشمند:** در صورت مسدود شدن سرور یا در دسترس نبودن تلگرام، به صورت خودکار از سرور جایگزین برای دریافت پروکسی‌ها استفاده می‌کند.
- 🛡️ **امنیت بالا:** فقط ادمین (شما) حق ارسال دستور به ربات و تغییر تنظیمات را دارد.

## 🛠️ پیش‌نیازها
قبل از شروع، به موارد زیر نیاز دارید:
1. یک حساب کاربری رایگان در [Cloudflare](https://dash.cloudflare.com/).
2. یک ربات تلگرامی (با مراجعه به [@BotFather](https://t.me/BotFather) یک ربات بسازید و `Token` آن را کپی کنید).
3. آیدی عددی تلگرام خودتان (از ربات [@userinfobot](https://t.me/userinfobot) دریافت کنید - مثلاً `123456789`).

## 🚀 آموزش نصب و استقرار (Deployment)

### مرحله ۱: ساخت فضای KV (پایگاه داده کلودفلر)
1. وارد داشبورد کلودفلر شوید و از منوی سمت چپ به مسیر **Workers & Pages > KV** بروید.
2. روی **Create a namespace** کلیک کنید.
3. یک نام دلخواه (مثلاً `PROXY_META`) وارد کنید.
4. در بخش نوع (Data Location)، گزینه **Standard** را انتخاب کرده و دکمه **Add** را بزنید.

### مرحله ۲: ایجاد و استقرار Worker
1. از منوی سمت چپ کلودفلر به **Workers & Pages** بروید و روی **Create Worker** کلیک کنید.
2. یک نام برای API خود انتخاب کنید (مثلاً `tg-proxy-api`) و روی **Deploy** کلیک کنید.
3. روی دکمه **Edit Code** کلیک کنید.
4. تمام کدهای موجود در فایل `worker.js` در این مخزن را کپی کرده و جایگزین کدهای پیش‌فرض کلودفلر کنید.
5. در بالا سمت راست، روی **Save and Deploy** کلیک کنید.

### مرحله ۳: اتصال KV به Worker (Binding)
1. به صفحه اصلی تنظیمات Worker خود برگردید.
2. از منوی بالا به تب **Settings** بروید و از سمت چپ گزینه **Variables** را انتخاب کنید.
3. اسکرول کنید تا به بخش **KV Namespace Bindings** برسید.
4. روی **Add binding** کلیک کنید.
5. در کادر **Variable name** دقیقاً کلمه `META_KV` را با حروف بزرگ بنویسید.
6. در کادر **KV namespace**، فضایی که در مرحله ۱ ساختید (مثلاً `PROXY_META`) را انتخاب کنید.

### مرحله ۴: تنظیم متغیرهای محیطی (Environment Variables)
در همان صفحه **Variables**، کمی بالاتر به بخش **Environment Variables** بروید و روی **Add variable** کلیک کنید. مقادیر زیر را اضافه کنید (نوع آن‌ها را روی `Text` بگذارید):

**متغیرهای اجباری:**
- `BOT_TOKEN` : توکن رباتی که از BotFather گرفتید.
- `ADMIN_ID` : آیدی عددی تلگرام شما.

**متغیرهای اختیاری (در صورت عدم تنظیم، از پیش‌فرض‌های کد استفاده می‌شود):**
- `MAX_POSTS` : تعداد پست‌هایی که برای پیدا کردن پروکسی بررسی می‌شوند (پیش‌فرض: 10).
- `MAX_PROXIES` : حداکثر تعداد پروکسی‌های خروجی (پیش‌فرض: 50).
- `CACHE_TTL` : زمان کش شدن نتایج به ثانیه برای افزایش سرعت (پیش‌فرض: 60).

در نهایت روی **Save and Deploy** کلیک کنید. *(نکته: اگر کلودفلر پیامی درباره آپدیت فایل `wrangler.toml` داد، آن را نادیده بگیرید).*

### مرحله ۵: تنظیم Webhook ربات تلگرام
برای اینکه تلگرام پیام‌های ربات را به کد شما بفرستد، لینک زیر را با مشخصات خودتان پر کرده و در مرورگر (مانند کروم) باز کنید:

```text
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_WORKER_URL>
```
*راهنما:*
- جای `<YOUR_BOT_TOKEN>` توکن ربات را بگذارید.
- جای `<YOUR_WORKER_URL>` آدرس Worker خود (مثلاً `https://tg-proxy-api.username.workers.dev`) را بگذارید.

✅ **اگر موفقیت‌آمیز باشد، در مرورگر این پیام را می‌بینید:**
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

## 📱 راهنمای دستورات ربات تلگرام
کافیست وارد ربات خود شوید و دستورات زیر را ارسال کنید. ربات بلافاصله تغییرات را در KV ذخیره کرده و در API اعمال می‌کند:

- `/title [متن دلخواه]` ➔ تغییر عنوان (مثلاً `/title پروکسی‌های پرسرعت`)
- `/desc [متن دلخواه]` ➔ تغییر توضیحات
- `/link [آدرس لینک]` ➔ تغییر لینک کانال یا سایت شما
- `/image [آدرس عکس]` ➔ تغییر بنر یا آیکون نمایشی
- `/ads on` ➔ روشن کردن نمایش تبلیغات در اپلیکیشن کلاینت
- `/ads off` ➔ خاموش کردن نمایش تبلیغات

## 🌐 نحوه استفاده از API

لینک Worker شما همان API شماست. کلاینت (یا اپلیکیشن شما) باید با متد `GET` به آن درخواست بدهد.

**دریافت پروکسی‌های کانال پیش‌فرض:**
```http
GET https://tg-proxy-api.username.workers.dev/
```

**دریافت پروکسی از کانال‌های دلخواه:**
```http
GET https://tg-proxy-api.username.workers.dev/?channel=ProxyMTProto,MTProto
```

**اعمال محدودیت در خروجی:**
```http
GET https://tg-proxy-api.username.workers.dev/?channel=proxy&posts=5&limit=15
```
